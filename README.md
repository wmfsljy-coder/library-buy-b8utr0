# 웅천고 도서관 구입 목록 도우미

도서관 담당 교사가 학교도서관 구입 예정 목록을 만드는 웹 도구입니다.

- 권수(기본 100권)를 넣으면 청소년 권장도서·신간·진로 책을 분야 균형에 맞춰 고릅니다.
- 후보는 모두 독서로(웅천고) 장서와 대조해 **학교에 없는 책**입니다. 목록을 만든 뒤 ‘독서로로 다시 확인’으로 한 번 더 확인합니다.
- ‘품의용 엑셀’은 학교 「도서구입 예정 목록」 양식(순번·도서명·저자·출판사·권수·정가·합계)으로 내려받습니다. ‘검토용 엑셀’에는 선정 근거·ISBN이 함께 들어갑니다.
- 교사·학생 희망 도서는 ‘책 직접 넣기’로 더합니다.

자료: `data/books.json` (후보 도서, 알라딘 정가·분류, 추천 목록 출처). 학생 개인정보는 없습니다.
독서로·알라딘 조회는 Google Apps Script 중계(`relay/`)를 거칩니다.
